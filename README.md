# Game Turbo

Game Turbo is an Android app designed to optimize gaming performance. Boost your games with enhanced speed and stability.

## Download

Download the latest APK from the [releases](https://github.com/vvraju56/GameTrubo/releases) or directly from the website.

## Features

- **Game Detection** - Automatically detects installed games on your device
- **Game Boost Mode** - Optimize performance while gaming
- **Floating Overlay** - Display info overlay during games
- **Foreground Service** - Background monitoring for game optimization
- **Multiple Game Modes** - Choose from different boost profiles
- **Settings Panel** - Customize your gaming experience

## Tech Stack

- Kotlin
- Jetpack Compose (Material Design 3)
- Android SDK 34

## Permissions

- System Alert Window (Overlay permission)
- App Usage Tracking
- Foreground Service Support
- Package Query (detects all installed apps)
- Notification Support
